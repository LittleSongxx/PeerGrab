页面数据为一次性演示任务，不是生产数据。截图由 Playwright 在 1440×900 和 390×844 视口实拍。

- 桌面 1440×900：`login.png` / `square.png` / `publish.png` / `detail.png` / `wallet.png` /
  `credit.png` / `notifications.png` / `arbitration.png`
- 移动 390×844：`square-mobile.png` / `detail-mobile.png` / `wallet-mobile.png`
- 生成日期：2026-10-22
- 截图生成后请同步检查 [`README.md`](../../../README.md) 中的图片引用。

另有取消退款、争议仲裁、钱包流水、信用分与站内消息页面。
